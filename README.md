# Harshit — Personal Portfolio

Single-page portfolio site showcasing AI products, automation systems, and experiments built by Harshit.

## Stack

Vite + React 18 + TypeScript (strict) + Tailwind CSS 3.4 + framer-motion 12.

## Commands

- `npm install`
- `npm run dev`
- `npm run build`

## Deploy

Live on GitHub Pages: https://harshitio.github.io

`npm run build` → push `dist/` + `404.html` to the `harshitio/harshitio.github.io` repo (SPA fallback via `404.html`). Vercel is retired.
